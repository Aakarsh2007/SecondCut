# One paired operator review trial

Open `/comparison` on the running site. It performs no model, payment or API request. The user agreed to perform one final trial; until completed, human time saved remains unmeasured.

**Task:** review three actual saved Scenario A offers, record the worksheet calculations, select the protected eligible offer and acknowledge changed requirements. All other gates are held constant. This is a narrow policy-review subtask, not manual buyer discovery, negotiation, settlement or an end-to-end business benchmark.

**Manual mode:** the same facts, formula, quoted adaptation costs and candidate terms are shown without calculated stressed margins. The operator records each stressed margin, selects an offer and acknowledges changed terms. Correctness is required, with unsuccessful submissions and elapsed time retained.

**Assisted mode:** the same offer terms and saved deterministic results are shown. The operator reviews the saved results, selects the eligible option and acknowledges changed terms. Calculation transcription is avoided because it is already stored, but the responsibility to review remains.

**Measurements:** monotonic elapsed wall time from each Start click to the correct Submit; change events; distinct form fields changed; submit attempts; correctness. Inter-stage waiting is excluded. Think time, typing and interruptions inside a task are included. Distinct form fields and browser change events are not total human actions or cognitive effort. Pasting and keyboard patterns affect event counts.

**Limits:** one self-reported operator, one synthetic scenario, manual first and assisted second. Learning/carryover bias, lack of blinding, novice/expert differences and the task's transcription requirements limit interpretation. Model-generation time is excluded from this review subtask and must not be hidden if presenting complete workflow timing. Client timing is not independently audited. Preserve negative results too. Do not generalize a positive difference to merchants or claim a percentage of total work saved.

The completed JSON stays in browser local storage. Copy it back for the release record; no email, account identity or secret is collected and no file is automatically added to Downloads.
